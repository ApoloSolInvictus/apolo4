# Sitio de presentación de Apolo4

Landing estática en español. Se puede alojar desde esta carpeta en cualquier hosting estático.

## Vista previa

Desde la raíz del proyecto ejecuta:

```bash
npm run site:dev
```

## Compilación

```bash
npm run site:build
```

La salida lista para publicar queda en `website/dist/`.

La ilustración de Apolo se generó para esta página. La captura de la interfaz es una imagen real de Apolo4.
